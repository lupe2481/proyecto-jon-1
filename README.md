# Portafolio Digital — María Guadalupe García

Portafolio web de diseño gráfico con enfoque en branding, motion graphics e ilustración. Sitio de una sola página con diseño responsivo, tipografías personalizadas (ITTrivane y Franie), animaciones CSS y una paleta cromática definida por rosa, azul y naranja.
